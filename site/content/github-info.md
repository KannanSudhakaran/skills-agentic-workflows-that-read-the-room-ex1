# GitHub Info

## Mona's editorial angle

Mona's website focuses on practical GitHub guidance backed by official references from:

- docs.github.com
- github.blog

## Current homepage themes

- GitHub collaboration basics: repositories, branches, pull requests, and merges.
- GitHub Copilot as an AI coding assistant across the IDE, CLI, and GitHub.
- GitHub Actions as the automation layer behind repository workflows.
- Recent GitHub Blog and Changelog stories worth watching.

## Recent updates

- **Copilot code review, more request options** — You can now request and configure Copilot code reviews in more ways. ([GitHub Changelog, Sep 23, 2026](https://github.blog/changelog/2026-09-23-copilot-code-review-more-ways-to-request-and-configure-reviews))
- **Node 20 retired in Actions** — Actions runners no longer support Node 20; update workflows to Node 24 (or the current supported version) to avoid breakage. ([GitHub Changelog, Sep 23, 2026](https://github.blog/changelog/2026-09-23-node-20-is-no-longer-available-in-github-actions))
- **Local sandboxing in the GitHub Copilot app** — Adds a sandboxed local execution mode for agent runs. ([GitHub Changelog, Sep 23, 2026](https://github.blog/changelog/2026-09-23-local-sandboxing-in-the-github-copilot-app))
- **New model options in Copilot** — Claude Opus 5.5 and OpenAI's GPT-6 Sol/GPT-6 Luna are now available as model choices in GitHub Copilot. ([GitHub Changelog, Sep 22, 2026](https://github.blog/changelog/2026-09-22-claude-opus-5-5-is-now-available-in-github-copilot))
- **Proof of presence for high-impact actions** — Sensitive actions (like deleting a repo) now require a fresh proof-of-presence check. ([GitHub Changelog, Sep 24, 2026](https://github.blog/changelog/2026-09-24-require-proof-of-presence-for-high-impact-actions))
- **When chat is the wrong UI** — A look at when a conversational interface helps vs. hinders developer workflows, useful context for teams building on Copilot. ([GitHub Blog](https://github.blog/ai-and-ml/github-copilot/when-chat-is-the-wrong-ui/))
